# מדיניות פרטיות — קיבוץ גרופית

אפליקציה זו מיועדת לשימוש פנימי של קיבוץ גרופית בלבד.

## איסוף מידע
האפליקציה אוספת שם משתמש ופרטי התקשרות לצורך ניהול אירועים פנימיים.

## שימוש במידע
המידע משמש לניהול אירועים, התנדבויות ותקציב פנימי בלבד.

## שיתוף מידע
המידע אינו משותף עם גורמים חיצוניים.
